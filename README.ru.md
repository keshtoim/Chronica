# Chronica

[English](README.md) · **Русский**

Календарь, планировщик задач и трекер привычек с игровыми элементами в духе Habitica — одно приложение без собственного сервера. Работает как сайт, устанавливается как десктоп-приложение под Windows и как Android-приложение из единого кодбейса.

## Возможности

- 📅 **Календарь** — виды «месяц/неделя/день/повестка дня», повторяющиеся события (RRULE), перетаскивание и изменение длительности, события на весь день и многодневные
- ✅ **Задачи** — списки в стиле Google Tasks с вложенными подзадачами; сортировка вручную, по дате создания или по сроку (у подзадачи в списке виден родитель для контекста)
- 🔥 **Привычки** — ежедневные/еженедельные/по выбранным дням привычки, стрики, heatmap выполнения в стиле GitHub
- 🧙 **Геймификация** — XP, уровни, золото, HP и магазин наград; выполнение задач и привычек начисляет награды, пропущенные ежедневные привычки отнимают HP
- 🎨 **Кастомизация** — своё фото с кроппингом для любой задачи или события, настройка фона приложения (кроп, блюр, фильтры)
- 🔄 **Синхронизация между устройствами** через резервную копию на Google Drive (сейчас — локальная заглушка за общим интерфейсом `SyncProvider`, реальный провайдер на Google Drive планируется)
- 📦 **Без сервера** — один кодбейс работает как сайт, устанавливаемое десктоп-приложение под Windows и Android-приложение

## Стек

| Слой             | Выбор                                                        |
| ---------------- | ------------------------------------------------------------ |
| UI               | React + TypeScript + Vite, Tailwind CSS                      |
| Оболочка         | [Tauri v2](https://v2.tauri.app/) (Windows exe, Android APK) |
| Локальные данные | Dexie.js (IndexedDB), offline-first                          |
| Состояние        | Zustand                                                      |
| Drag & drop      | dnd-kit                                                      |
| Повторения       | rrule.js                                                     |
| Кроппинг фото    | react-easy-crop                                              |

## Разработка

```bash
npm install
npm run dev          # сайт в браузере, http://localhost:5173
npm run build         # production-сборка сайта
npm run lint           # oxlint
npm run format         # prettier --write
npm run typecheck      # tsc -b
```

Для запуска десктопной Tauri-оболочки локально нужен установленный Rust-тулчейн ([rustup.rs](https://rustup.rs/)):

```bash
npm run tauri dev
```


## Синхронизация

Синхронизация между устройствами при запуске забирает снапшот данных, сливает его с локальными изменениями и отправляет обратно — сейчас реализовано поверх локальной `MockLocalSyncProvider`. Реальный провайдер на Google Drive заменит её за тем же интерфейсом `SyncProvider`, без изменений в вызывающем коде.

## Сборка и релизы

GitHub Actions собирает три артефакта: сайт (деплой на GitHub Pages), Windows `.exe` и Android `.apk`. Подробности — в `.github/workflows/`.
