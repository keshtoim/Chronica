# Chronica

[English](README.md) · **Русский**

Календарь, планировщик задач и трекер привычек с игровыми элементами в духе Habitica — одно приложение без собственного сервера. Работает как сайт, устанавливается как десктоп-приложение под Windows и как Android-приложение из единого кодбейса.

## Возможности

- 🏠 **Дашборд** — стартовый экран в духе Habitica: уровень/XP/HP/золото на виду, задачи и события на сегодня, привычки и магазин наград в одном месте
- 📅 **Календарь** — виды «месяц/неделя/день/повестка дня», повторяющиеся события (RRULE), перетаскивание и изменение длительности, события на весь день и многодневные
- ✅ **Задачи** — списки в стиле Google Tasks с вложенными подзадачами; сортировка вручную, по дате создания или по сроку (у подзадачи в списке виден родитель для контекста)
- 🔥 **Привычки** — ежедневные/еженедельные/по выбранным дням привычки, стрики, heatmap выполнения в стиле GitHub
- 🧙 **Геймификация** — XP, уровни, золото, HP, магазин наград и достижения за реальный прогресс (уровни, выполнения, стрики); выполнение задач и привычек начисляет награды, пропущенные ежедневные привычки отнимают HP
- 📜 **Торговец** — можно купить за золото «свиток пропуска» в магазине, чтобы закрыть пропущенный день привычки без урона HP и без разрыва стрика
- 👋 **Онбординг** — короткий тур при первом запуске, объясняющий каждый раздел перед тем, как попасть на дашборд
- 🎨 **Кастомизация** — своё фото с кроппингом для любой задачи или события, настройка фона приложения (кроп, блюр, фильтры), премиальный glassmorphism-интерфейс с анимациями на Framer Motion
- 📱 **Адаптивность** — отзывчивый layout с нижней панелью вкладок на маленьких экранах, с учётом safe-area под вырезы/жест-панели
- 🔄 **Синхронизация между устройствами** через личный Google Drive пользователя (`appDataFolder`) — OAuth для веба (Google Identity Services), десктопа (loopback + PKCE) и Android (deep link + PKCE); до подключения аккаунта работает локальная заглушка за тем же интерфейсом `SyncProvider`
- 📦 **Без сервера** — один кодбейс работает как сайт, устанавливаемое десктоп-приложение под Windows и Android-приложение

## Разработка

```bash
npm install
npm run dev          # сайт в браузере, http://localhost:5173
npm run build         # production-сборка сайта
npm run lint           # oxlint
npm run format         # prettier --write
npm run typecheck      # tsc -b
```

Для запуска десктопной Tauri-оболочки локально нужен установленный Rust-тулчейн ([rustup.rs](https://rustup.rs/)):

```bash
npm run tauri dev
```

## Синхронизация

Синхронизация между устройствами при запуске забирает снапшот данных, сливает его с локальными изменениями (last-write-wins по каждой записи) и отправляет обратно. `GoogleDriveSyncProvider` хранит снапшот в личном `appDataFolder` самого пользователя в Google Drive — данные никогда не попадают на сервер, которым управляет Chronica. Пока аккаунт не подключён, синхронизация работает поверх локальной `MockLocalSyncProvider` за тем же интерфейсом — вызывающий код не зависит от того, какой бэкенд активен.

## Сборка и релизы

GitHub Actions собирает три артефакта на каждый тег `v*`: сайт (деплой на GitHub Pages), Windows `.exe` и Android `.apk` — воркфлоу Windows и Android прикрепляют свои инсталляторы к одному и тому же черновику GitHub Release. Подробности — в `.github/workflows/`.
